# Ramping-Up Hippocampal Ripples and Their Neocortical Coupling Support Human Visual Short-Term Memory

**Authors**: Jing Liu, Xianhui He, Can Yang, Nikolai Axmacher, Gui Xue, Shaoming Zhang, Ying Cai
**Posted**: 2026-04-08 (v1), 2026-07-27 (v2), *bioRxiv*
**DOI**: 10.64898/2026.04.07.716930
**License**: CC-BY-NC-ND 4.0 International
**Tags**: `human-brain` `hippocampus` `ripples` `short-term-memory` `VSTM` `iEEG` `neocortical-coupling` `lateral-temporal-lobe`

## Summary

Using intracranial EEG recordings from human participants performing a delayed match-to-sample task for naturalistic objects, this study investigated the role of hippocampal ripple activity in visual short-term memory (VSTM) maintenance and hippocampal-neocortical communication.

### Key Findings

1. **Ramping ripple rates** — Hippocampal ripple rates progressively ramped up during the VSTM maintenance period
2. **Behavioural relevance** — Ripple rate during maintenance predicted successful VSTM performance
3. **Hippocampal-LTL coupling** — Hippocampal ripples were temporally coupled with ripples in the lateral temporal lobe (LTL)
4. **Memory reactivation** — Coupled ripples were associated with memory reactivation in the LTL, linking oscillatory events to content-specific replay

### Interpretation

These findings provide direct electrophysiological evidence that hippocampal-neocortical interaction via coupled ripples supports VSTM, extending the canonical view of hippocampal ripples from exclusively long-term consolidation to also encompass short-term mnemonic processes. The ramping profile suggests active maintenance rather than purely retrospective encoding.

### Significance

This is the first direct demonstration that hippocampal ripples — classically associated with sleep-dependent memory consolidation and spatial navigation — play a functional role in human visual short-term memory maintenance. The temporal coupling between hippocampal and neocortical ripples during active maintenance challenges the strict division between working memory and long-term memory systems.
