# Stationary covariance spectra of discrete-time non-normal random recurrent dynamics

**Date:** 2026-06-30  
**arXiv:** https://arxiv.org/abs/2606.31944

Using a free-probability approach, this note derives a closed functional equation for the limiting stationary covariance spectrum of discrete-time RNNs with random non-normal Gaussian weights.

## Key Findings
- **Closed Scalar Equation:** Derived a functional equation for the moment-generating function of the covariance spectrum in discrete-time dynamics.
- **Critical Regime Analysis:** The characterization allows for precise analysis of tail eigenvalues near the stability edge.
- **Divergence from Continuous Time:** Unlike discrete-time, continuous-time dynamics results in an infinite hierarchy of Schwinger-Dyson equations, preventing a simple scalar closure for the covariance spectrum.
- **PCA Relevance:** Provides the theoretical foundation for understanding variance distribution in large non-normal recurrent networks.
