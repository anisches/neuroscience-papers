# Transregional Neural Prostheses: Applications and Computational Tools

**DOI:** [10.1109/TNSRE.2026.3717163](https://doi.org/10.1109/TNSRE.2026.3717163)  ·  **Authors:** Shenghui Wu, Jose Principe, Yiwen Wang  ·  **Date:** 2026-07-27 (IEEE Trans Neural Syst Rehabil Eng, ahead of print)

**Tags:** `computation` `neural-prostheses` `transregional` `neural-interfaces` `computational-models` `neural-rehabilitation` `brain-computer-interfaces`

A comprehensive review defining transregional neural prostheses as a distinct paradigm that re-establishes endogenous causal communication between brain circuits — moving beyond classic sensory/motor prostheses (cochlear implants, motor BCIs) that replace function with external devices. The review surveys current applications across limb motor control, cognitive restoration (memory, attention), and long-term rehabilitation; systematically categorises computational models into predictive models (encoding/decoding inter-region dynamics) and stimulation optimisation models (closed-loop adaptive control); and outlines future directions in neural engineering, circuit-level neuroscience, and clinical translation.

**Key contribution:** Provides the first unified computational framework for transregional neural prostheses, clarifying that the core challenge is not electrode development but building computational models of inter-region neural communication, and that limited understanding of distributed brain computation is now the primary bottleneck for next-generation neural rehabilitation.
